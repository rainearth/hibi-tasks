# Hibi（ヒビ）— iPhone向け個人用タスク＆ルーティンWebアプリ

iPhoneで片手でも快適に使える、**完全無料・ログイン不要・オフライン対応（PWA）** の個人向けタスク管理Webアプリです。
外部パッケージやビルドツールを使わない軽量構成のため、そのまま無料ホスティングサービスに公開してすぐ使い始められます。

---

## 主な機能

- **今日のタスク＆進捗リング**：今日やることを「期限切れ」「今日のルーティン」「今日のタスク」「今日完了」に分けて整理。期限切れはワンタップでまとめて今日に変更できます。
- **繰り返しタスク（ルーティン）**：毎日・平日・毎週（曜日複数選択）・毎月に対応。完了すると連続達成回数（ストリーク）がカウントされ、次回予定日が自動更新されます（間違えても「元に戻す」やチェック解除で完全復元）。
- **期限・優先度・カテゴリ分け**：ワンタップの期限チップ（今日・明日・今週末・来週）、優先度（高・中・低・なし）、色付きカテゴリの自由な追加・削除に対応。
- **サブタスク＆メモ**：チェックリスト形式のサブタスク（カード上で直接展開＆チェック可能）と、URLリンク自動認識付きのメモ機能。
- **iPhone端末内保存＆バックアップ**：データは端末内の `localStorage` に自動保存。設定画面からJSON形式でバックアップ書き出し・復元ができます。
- **iPhoneホーム画面アプリ化（PWA）**：Safariの「ホーム画面に追加」からフルスクリーン＆オフラインで起動できます。ライト／ダークモード自動切替＋5色のテーマカラー対応。

## 1. 手元（PC / 同じWi-FiのiPhone）で試す

このフォルダで次のコマンドを実行してください：

```bash
node scripts/serve.mjs
```

表示されたURLを開くと動作確認できます：
- **PCブラウザ**：`http://localhost:5173`
- **同じWi-FiのiPhone**：表示された `http://192.168.x.x:5173` をSafariで開く

---

## 2. 完全無料で公開してiPhoneで毎日使う方法

静的ファイル（HTML / CSS / JS）だけで動くため、以下のサービスで**ずっと無料（HTTPS対応）** で公開できます。HTTPSで公開すると、iPhoneのオフライン機能（Service Worker）もフルに動作します。

### 方法A：Netlify Drop（一番かんたん・登録後ドラッグ＆ドロップだけ）
1. [Netlify Drop](https://app.netlify.com/drop) を開く（無料アカウントを作成）
2. このフォルダ（`index.html` 等が入っているフォルダ）をそのままドラッグ＆ドロップ
3. 発行された `https://〜.netlify.app` のURLをiPhoneのSafariで開く

### 方法B：GitHub Pages（無料）
1. GitHubで新しいリポジトリを作成し、このフォルダのファイルをすべてアップロード（または `git push`）
2. リポジトリの **Settings → Pages** を開き、Sourceを `Deploy from a branch`、Branchを `main` / `/ (root)` にして保存
3. 数分後に発行される `https://<ユーザー名>.github.io/<リポジトリ名>/` をiPhoneのSafariで開く

### 方法C：Cloudflare Pages（無料・高速）
1. Cloudflareダッシュボード → **Workers & Pages → Create → Pages → Upload assets**
2. このフォルダをアップロードして公開

---

## 3. iPhoneのホーム画面に追加する（アプリ化）

1. 公開したURLを **iPhoneのSafari** で開く
2. 画面下の **共有ボタン（□↑）** をタップ
3. 下へスクロールして **「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ

これでホーム画面に **Hibi** のアイコンが追加され、アドレスバーなしのフルスクリーンでネイティブアプリのように使えます！
